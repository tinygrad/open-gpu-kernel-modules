# NVIDIA driver 570.133.20 with P2P for 4090

This allows using P2P on 4090 GPUs with the 570.133.20 driver version.
See https://github.com/tinygrad/open-gpu-kernel-modules for more info.

## How to Build

1) Install https://www.nvidia.com/en-us/drivers/details/242548/
  - Release Note: https://docs.nvidia.com/datacenter/tesla/tesla-release-notes-570-133-20/index.html
3) Run `./install.sh`
4) Reboot
